# omarchy-quicklook

Демон быстрого просмотра (Quick Look) для GNOME Files на Omarchy: по пробелу показывает превью файла в окне на Qt 6/QML. Подменяет `org.gnome.NautilusPreviewer`, то есть заменяет GNOME Sushi.

## Зачем

Sushi на Omarchy: окно фиксированного размера 875×600 независимо от содержимого, медленный холодный старт, слабая поддержка форматов (офис, RAW, HEIC, видео), неудобное управление. Здесь окно подгоняется под содержимое, демон живёт всё время сессии и стартует мгновенно. Замерено: окно появляется через 13–90 мс после пробела, его размер после показа не меняется, видео и звук стартуют через ~0,5 с.

## Установка

```
./install.sh
```

Ставит зависимости (`omarchy-pkg-add`), собирает, гоняет тесты, кладёт бинарник в `~/.local/bin`, пользовательскую службу systemd и D-Bus-файл, отключает `sushi.service`. Повторный запуск обновляет сборку.

## Клавиши

| клавиша | действие |
|---|---|
| Пробел, Esc, Q | закрыть |
| Enter, двойной щелчок | открыть в программе по умолчанию, закрыть |
| ← → ↑ ↓ | перейти к соседнему файлу в Files |
| Del | в корзину и к следующему файлу (последний в папке — к предыдущему, единственный — закрыть); удаляет сам Files, Ctrl+Z в Files возвращает последний удалённый |
| Ctrl +, Ctrl −, Ctrl 0 | зум: картинки, PDF и офис, текст и код (шрифт); Ctrl 0 — исходный вид |
| Ctrl ← → ↑ ↓, перетаскивание | сдвиг увеличенного содержимого |
| колесо, PgUp/PgDn, Home/End | прокрутка (текст, PDF) |
| F, F11 | полный экран / обратно |
| K, P, щелчок по видео | пауза / продолжить |
| J, L | −10 с / +10 с |
| M | звук выкл/вкл (запоминается в `~/.local/state/omarchy-quicklook/state.ini`) |

Буквенные клавиши работают и в русской раскладке.

## Как это работает

Служба systemd (`Type=dbus`) держит имя `org.gnome.NautilusPreviewer` весь сеанс. Files вызывает `ShowFile` по D-Bus, демон определяет тип файла, считает размер окна под содержимое и показывает единственное окно `QQuickWindow`; стрелки он шлёт обратно в Files как `SelectionEvent` и ждёт следующий `ShowFile`. Офисные документы конвертируются в PDF через LibreOffice. Если демон упал, systemd его перезапускает.

Рекомендуемое правило Hyprland:

```lua
o.window("^(omarchy-quicklook)$", { float = true, center = true, no_anim = true, tag = "-default-opacity", opacity = "1 1" })
```

## Чего нет в v1

Выделение и копирование текста; ввод пароля PDF/офиса; номера строк; Markdown в оформленном виде; привязка окна к окну Files (xdg-foreign); сигналы Files 51 (`NavigateTo`, `Rename`, `Trash`); аппаратное декодирование видео; вынос рискованных декодеров в отдельный процесс; содержимое архивов.

## Разработка

```
cmake -B build -G Ninja && cmake --build build && ctest --test-dir build -LE perf
```

Живая проверка без Files: вызвать `ShowFile(uri, "", true, "")` на `/org/gnome/NautilusPreviewer` (`org.gnome.NautilusPreviewer2`) из процесса, который держит соединение с шиной, — когда вызывающий отключается, превью закрывается. Вызов с `false` при скрытом окне игнорируется, как у Sushi.

## Откат

```
./uninstall.sh
```

Files вернётся к `sushi` из пакета, но без обходов 2026-10-13 (окно 875×600, холодный старт). Пакет `sushi` не удаляется.
